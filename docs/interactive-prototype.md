# Interactive Prototype Flows

## Account Opening Flow
1. Click **Open Account** in header
2. Complete modal form (name, email, password)
3. Confirm MFA checkbox
4. Submit to trigger success state and onboarding toast

## Loan / Goal Discovery Flow
1. Enter a goal in "Tell us your goal"
2. Recommendation engine returns relevant product set
3. User selects card and continues to pre-qualification

## Demo Banking Flow
1. Launch sandbox demo
2. View high-balance test account
3. Execute withdraw action to validate transactional UI feedback
