# FirstGreen Design System

## Color Tokens
- `--midnight`: `#0A192F`
- `--charcoal`: `#2D3748`
- `--gold`: `#D4AF37`
- `--teal`: `#38B2AC`
- `--soft`: `#F7FAFC`

## Typography
- Heading: Playfair Display (600-700)
- Body/UI: Inter (400-700)
- Base size: 16px with responsive heading clamp

## Spacing & Grid
- 8px base scale
- 12-column responsive intent (implemented through CSS grid variants)
- 8px corner radius, soft elevated shadows

## Component Library
- Sticky Glass Header
- Dropdown Navigation / Mobile Overlay
- Hero + Quick Access Card Strip
- Service Discovery Cards
- Dashboard Sandbox Widgets
- Testimonial Masonry
- Education Calculator Cards
- Rates Ticker
- Footer Mega Grid
- Modal Account Onboarding
