# FirstGreen Enterprise Financial Platform Demo

Production-style SPA/PWA prototype for a modern digital banking experience with enterprise-oriented UX patterns, onboarding, rates, and demo dashboard.

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Included deliverables
- Website implementation: `index.html`, `styles.css`, `app.js`
- PWA: `manifest.webmanifest`, `sw.js`
- Brand asset: `assets/logo-fg.svg`
- Documentation: `docs/design-system.md`, `docs/technical-documentation.md`, `docs/content-strategy.md`, `docs/analytics.md`
